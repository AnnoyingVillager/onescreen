# OneScreen 范围与验收标准

## 产品目标

OneScreen 在 Minecraft 世界中提供可贴附于任意方块表面的薄型屏幕，通过服务端保存的 URL 播放图片、视频和声音。服务器决定屏幕配置，各客户端在本地异步解析媒体、管理播放器并独立计算距离音量。

## 当前用户流程

1. 玩家从 `OneScreen` 创意栏取得 1x1x1/16 的屏幕画框。
2. 将画框贴在任意方块的六个表面之一。
3. 右键画框打开编辑器，或由管理员使用 `/screen` 命令配置。
4. 服务端校验并保存 URL、尺寸、距离、九宫格位置、适配模式等设置。
5. 客户端收到方块实体更新后异步创建媒体会话并渲染画面。
6. 玩家离开区块、切换维度或断线时释放媒体资源；返回后重新加载。

## 已实现功能范围

### 方块与渲染

- 六向薄画框，支持水平四向及朝上、朝下表面。
- 可挖掘、掉落、独立创意栏、模型、碰撞、贴图和 loot table。
- 无媒体且 debug 关闭时显示区域透明；debug 开启后显示占位材质。
- 支持隐藏静态画框，同时保留动态媒体和右键交互。
- 支持 `-180°` 到 `180°` 的屏幕平面内旋转。
- 支持 `fit`、`stretch`、`tile`、`fill`、`center` 五种画面适配模式。
- 支持 OpenGL 与 Vulkan 图形后端；0.2 优先使用 WATERMeDIA GPU 纹理，失败时回退 CPU 纹理。

### 屏幕设置

- HTTP/HTTPS 媒体 URL。
- 屏幕宽度与高度，单位为方块。
- 九宫格相对位置及屏幕平面旋转。
- 渲染距离、声音传播距离、音量、静音和循环。
- 隐藏画框、直播追帧、加载修订号。
- 旧存档缺少新字段时使用明确默认值。

### 媒体与播放器

- 图片、视频、HLS/M3U8 和音频由 WATERMeDIA 3 管理。
- 支持播放、暂停、停止、手动刷新和循环。
- 已知时长媒体可拖动进度；直播进度条只读。
- 自动刷新直播默认关闭，只对直播流在暂停恢复或配置更新后生效。
- 多频道 IPTV 列表当前只使用第一个源。
- 不设置 OneScreen 侧的固定 1080p 上限；`LOD=MAX` 使用 WATERMeDIA 实际输出尺寸。

### 同步与安全

- 服务端是 URL 和屏幕设置的唯一权威。
- 方块实体更新包负责世界同步与后进服玩家同步。
- 编辑器与刷新按钮通过受校验的自定义 payload 提交。
- 修改命令要求权限等级 2；`/screen info` 对所有玩家开放。
- URL 只接受 HTTP/HTTPS，并限制长度、主机和控制字符。

### 配置

- `config/onescreen.json` 提供最大渲染距离与最大声音距离。
- 默认上限为 `256` / `128`，配置硬上限为 `4096` / `1024`。
- 配置值用于指令和编辑器校验；实际距离仍受区块加载、客户端视距和服务端模拟距离限制。

## 非功能要求

- `src/main` 不引用 `net.minecraft.client.*`、纹理句柄、播放器或渲染类。
- 单客户端默认最多同时保留 8 个活动媒体会话，超限屏幕延迟创建。
- 所有网络解析、解码和媒体准备不得阻塞渲染线程。
- 每个屏幕最多一个活动播放器；URL、刷新修订或生命周期变化时先关闭旧会话。
- WATERMeDIA 版本差异集中在 `WaterMediaCompat` 与 `WaterMediaVersion`。
- Vulkan 必须使用 Minecraft graphics queue，并由共享队列锁覆盖提交、等待和呈现。
- 文档、日志和测试数据不得包含令牌、私钥、私人媒体 URL 或本机敏感路径。

## 明确不包含

- 播放列表管理、遥控器、媒体搜索、上传或转码服务。
- 多方块自动拼接、无缝大屏阵列或投影仪。
- 完整三维欧拉旋转；当前只支持屏幕平面内旋转。
- 按玩家保存不同 URL、复杂权限组或服务端 URL allowlist。
- 内置文件服务器、代理服务器或 DRM 绕过。
- IPTV 多频道自动切换。
- WaterVision、Valkyrien Skies、Sable 等第三方集成。

## 0.2 验收门槛

- `.\gradlew.bat build --offline --no-daemon --no-configuration-cache` 通过。
- 沙箱客户端可进入世界，六向渲染、点击和破坏掉落正常。
- 图片、VOD、HLS 元数据、暂停、停止、刷新和循环回归通过。
- 1080p 与 4K 至少各播放一次，并分别记录 `format=GPU/CPU` 与 `hardwareAccel=true/false`。
- OpenGL 与 Vulkan 均完成媒体路径回归。
- Vulkan 三个队列同步 Mixin 全部注入，且无 `VK_ERROR_DEVICE_LOST`。
- 区块卸载、维度切换和断线时没有残留播放器、纹理或声音。
- 当前未完成项必须保留在 [测试计划](TESTING.md)，不得写成已通过。
