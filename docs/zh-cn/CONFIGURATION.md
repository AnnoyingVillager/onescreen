# 配置文件

OneScreen 会在首次启动时生成：

```text
<游戏或服务端目录>/config/onescreen.json
```

默认内容：

```json
{
  "maxRenderDistance": 256.0,
  "maxAudioDistance": 128.0
}
```

## 字段

| 字段 | 默认值 | 允许范围 | 作用 |
|---|---:|---:|---|
| `maxRenderDistance` | `256.0` | `8.0`–`4096.0` | 单个屏幕可配置的最大渲染距离 |
| `maxAudioDistance` | `128.0` | `2.0`–`1024.0` | 单个屏幕可配置的最大声音传播距离 |

## 生效方式

- 单人游戏由集成服务端读取该配置。
- 专用服务器由服务端读取，并通过编辑界面同步给打开 GUI 的玩家。
- 修改后需要重启游戏或服务端。
- 配置只限制新的编辑和指令修改；已有屏幕数据不会因降低上限而被自动裁剪。
- 过大距离会增加客户端媒体会话、纹理上传和声音计算的负担，请根据设备能力设置。
- 实际可见距离仍受客户端区块渲染距离、服务端模拟距离和区块加载状态限制。
